Exercise: 13: Removing Duplicates#

Exercise Description#

Write a function remove_dups(L1, L2) that removes all elements from L1 that are also in L2.

Your solution#

def remove_dups(L1, L2):
    L1_copy = L1[:]
    for item in L1_copy:
        if item in L2:
            L1.remove(item)
    return L1


L1 = [1, 2, 3, 4]

print(remove_dups(L1, L2))
